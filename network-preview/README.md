# WETHUS Network OS Preview

WETHUS의 기존 블랙/오렌지 디자인 언어를 유지하면서, 프로젝트 목록 중심 구조를 사람과 활동 중심의 Network OS로 전환한 인터랙티브 디자인 체크포인트입니다.

## 로컬 실행

```powershell
python -m http.server 8092 --directory network-preview
```

브라우저에서 `http://127.0.0.1:8092/#for-you`를 엽니다.

## 구현 범위

- 개인화된 `For You` 브리프와 다음 행동
- 역할/가용성 근거가 포함된 People Discovery
- 활동과 열린 역할 중심의 Projects
- 프로젝트 단계와 필요 자원 기반 Opportunities
- ASK 생성, OFFER, semantic activity 흐름
- 활동에서 자동 정리되는 Living Portfolio
- 프로젝트 Workspace와 문맥형 Network Copilot
- 모바일 전용 헤더와 하단 내비게이션

프로젝트 시작 및 프로필 편집은 전환 기간 동안 현재 운영 중인 WETHUS 흐름으로 연결됩니다. 실제 인증, 클라우드 동기화, 추천 모델, 외부 도구 수집기는 다음 구현 슬라이스에서 기존 백엔드와 단계적으로 결합합니다.
